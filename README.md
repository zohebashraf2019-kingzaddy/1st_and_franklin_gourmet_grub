# 1st & Franklin Gourmet Grub Website

Static responsive HTML/CSS/JS site ready for GitHub and Vercel.

## Deploy
1. Upload all files/folders to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Other. No build command required.
4. Root directory: repository root.

## Update gallery
Add normalized images to `assets/`, then add filenames to the `images` array in `script.js` and gallery buttons in `index.html`.

## Contact form
The demo form currently opens the visitor's email app. Replace it later with Formspree, Web3Forms, Netlify Forms, or your preferred backend.
